# 周时间线 · v1 spec

Status: ready
Owner: 榛佑

## 一句话

一屏看见这一周，手填每条安排，能翻到任意一周继续填。

## 用户动作

1. 打开 → 默认落在「本周」（周一起始）。
2. 点某天的 `+` 或空白处 → 填标题、选时段、可选备注 → 保存，卡片出现在那天下面。
3. 点卡片 → 改标题/时段/备注，或删除。
4. 卡片 hover（触屏常显）→ `↑` `↓` 调整同一天同一时段内的先后。
5. 顶部 `‹ 上周`｜`本周`｜`下周 ›` 切换；也可从任意周继续前后翻。

## 领域规则

- **周**：ISO 周，周一→周日，标识 `YYYY-Www`。周不是数据，是查询区间；安排只记日期，跨周不迁移。
- **安排**：`{ id, date, slot, title, note, order }`，`date` 是唯一归属，`slot ∈ {am, pm, eve}`。
- **时段**：上午/下午/晚上三值，只表先后，不含具体时刻。
- **排序**：同一 `date + slot` 内按 `order` 升序；跨时段只能靠改时段，不能拖。

## 界面规则

- 桌面（≥820px）：7 列周轴，横向细线贯穿，每天一个节点；今天节点实心高亮；卡片在线下方按「上午→下午→晚上」堆叠。
- 手机（<820px）：换成单日卡片流 + 左右切天，不强行还原 7 列。
- 每张卡片带时段色点与文字标签；标题单行截断，备注最多两行截断。
- 空白天列底部保留淡 `+`，不显示"暂无数据"。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/items?from=&to=` | 区间内的安排，按 date,slot,order 排序 |
| POST | `/api/items` | 新增，body `{date, slot, title, note}` |
| PATCH | `/api/items/:id` | 改 `title/note/slot/date` |
| DELETE | `/api/items/:id` | 删除 |
| POST | `/api/items/:id/move` | body `{dir: "up"\|"down"}`，同 date+slot 内互换 |
| GET | `/api/health` | 存活探针 |

鉴权：全站 HTTP Basic，凭据来自环境变量 `AUTH_USER` / `AUTH_PASS`，任一为空则拒绝启动。

## 存储

`data/data.json` 单文件，写时先落 `data.json.tmp` 再 `rename`，覆盖前把旧文件复制为 `data.json.bak`（一步撤销）。

## 非目标（v1 明确不做）

- 多用户、账号体系、团队视图
- 拖拽排序、跨天拖动
- 重复安排 / 复制上周 / 周期性规则
- 周级（不落天）事项
- 提醒、通知、日历导出
