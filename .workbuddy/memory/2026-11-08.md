# 2026-11-08 · 「划掉一条安排」原型

## 已定结论（grill 阶段）
- 用户流程：学生请假 = 把卡拖到下一个时间点改期，**不是**划掉；划掉只表示「做完了」。
- 所以只做单一「完成」态，不做「作废」；数据用稀疏 `doneAt`（没有就不写），不铺 `done:false`，否则 contract.js 的逐字比对必红。
- 完成只改外观，不改交互：已完成的卡仍可拖、可编辑、可删、可取消勾（拖=改期，勾=记录，两件事正交）。上一轮「完成的卡不能拖」的推论已撤回。
- 不重排、不沉底：`placeItem` 的 index 按 DOM 顺序算，按 done 重排会让「眼前第几位」和「数据第几位」错位。
- 静止态 DOM 是基线（smoke.sh 第 2 项，CI 比 HEAD~1）：夹具没有 doneAt，所以划线与完成样式只要「有数据才出现」就不动基线；新增常驻控件才会破基线。
