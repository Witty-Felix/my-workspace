## 首屏 9 秒黑屏定位（20:00-20:25）
- 现象：手机微信首次进站全黑 9 秒，用一会儿后变顺、退出重进 0.5 秒。
- 定位证据：① 录屏逐帧亮度（V1 1.0→9.5s 全黑，10.0s 上屏；V2 1.5s 上屏）；② 服务器 gateway 日志：19:44-19:46 的请求来源是 104.23.251.x / 172.64.217.x（Cloudflare 网段），19:45:06 起变 113.194.242.30 直连；静态文件之间隔 5 秒。
- 结论：不是服务器慢（直连 TTFB 135ms）。是改 DNS 后 TTL=600 还没过期，手机仍解析到 Cloudflare 橙云地址，免费版大陆无节点 → 单次往返 ~1.9s × 串行 4-5 次。
- 二次放大因素：`index.html` 的 `#week` 是空 section，CSS 未到前浏览器不画任何东西 → 全程全黑无反馈。
- 收尾：用户删掉 Cloudflare 残留 + 飞行模式重连后复测，黑屏降到 **0.6 秒**，服务器只收到 HTML 304 + API 304（静态资源全命中缓存）。
- 待办：`docs/deploy.md`「换机器或换 IP 时」需补 TTL 600 会拖 10 分钟；骨架屏/内联首屏 CSS 方案待确认。
