## 建成：周工作台 v1（grill-with-docs 走完设计 → 已部署）

- 需求：一条横线展示一周安排，手填，可翻任意周继续填。
- 设计定案（GLOSSARY.md 已定词：周 / 周轴 / 安排 / 时段）：ISO 周周一起始；时段仅上午/下午/晚上三档；安排=标题+时段+备注，必落某天；排序用卡片上的 ↑↓；不做多用户、拖拽、复制上周、整周事项。
- 服务器实况（与最初假设相反，重要）：`139.224.192.94` 阿里云上海，Alibaba Cloud Linux 3，2C/1.8G；**无 nginx、无 PHP、无 Node**；`:80` 是 docker-proxy，跑 `vbcd` 五容器栈（`/home/bird/vbcd`）；宝塔只管面板（8888）；拦人的是阿里云安全组，不是 iptables。
- 因此 ADR 0001（PHP+JSON）被 ADR 0002（Docker+Node20+Express+JSON）取代。
- 产物：`app/`（server.js 222 行 / public 三件套）+ `Dockerfile` + `docker-compose.yml`；部署在 `/opt/workbench`，容器 `workbench`，宿主 8090；数据 `/opt/workbench/data/data.json` + `.bak`；Basic Auth 凭据在 `/opt/workbench/.env`（`joye` / 见 .env）。
- 踩坑：① 本机 `~/.ssh/id_ed25519` 带口令，非交互签不了名 → 另生成无口令 `~/.ssh/wb_deploy_ed25519`，公钥已加进服务器 authorized_keys；② healthcheck 打 `/api/health` 被 Basic Auth 401 → 探针移到鉴权之前，现在 `healthy`；③ 浏览器 `user:pass@` 不会传给 `fetch` → 本地预览用注入 Authorization 的代理（8110）绕过。
