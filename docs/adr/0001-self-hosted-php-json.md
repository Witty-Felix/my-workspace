# 自托管形态：静态前端 + 单文件 PHP 接口 + JSON 文件存储

工作台跑在自有的阿里云宝塔服务器上，以独立站点对外：前端是无构建的静态页，后端是一个 `api.php`，数据落在 `data.json`。这么选是因为这台机器的 `:80` 已被《buddy》站占用（不能覆盖原生 nginx 配置）、宝塔默认环境自带 nginx + PHP 而 Node 需另装版本管理器并常驻 PM2、单用户一周几十条数据上数据库纯属多余，且 JSON 文件可在面板里直接下载做备份。

## Considered Options

- **Node + Express + SQLite**：全栈同语言更顺手，但宝塔上要先装 Node 版本管理器、配 PM2 守护，多两个会出错的环节。
- **MySQL（宝塔自带）**：为几十行数据引入 schema 与连接配置，收益为零。
- **浏览器 localStorage**：零后端，但数据锁在一台电脑的浏览器里，换机或清缓存即丢，也违背「我有服务器」这个前提。

## Consequences

没有并发控制，靠「单用户 + 原子替换写（写临时文件再 rename）」扛住；一旦要多人协作，`api.php` 必须换成带事务的数据库实现，届时 ADR 应被新的替代。
